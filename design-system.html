A living reference of the site's tokens and components. Use the Edit tokens panel (bottom-right) to experiment with the brand colors live — every component below updates instantly.

  1. 1 Tweak colors in the panel, then hit Save — your changes survive a refresh, and the token values are copied to your clipboard.
  2. 2 Hand it to Claude: paste the copied values ("apply this:" + ⌘V), or just say what you changed.
  3. 3 Say "apply it" — Claude writes the values into this file, tailwind.config.ts, and app/globals.css, so the real site updates locally.
  4. 4 When you're happy, say "ship it" to deploy to the live site.
